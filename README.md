# rugby2027.ru

Независимый русскоязычный проект о регби. Репозиторий `rugbyworldgame/rwc-countdown`, публикация корня ветки `main` через GitHub Pages, действующий домен — https://rugby2027.ru.

## Начало работы в новой рабочей ветке или сессии

1. Получить актуальное состояние GitHub и проверить незакоммиченные изменения.
2. Перед работой с составами прочитать [постоянную документацию системы игроков](scripts/PLAYERS.md).
3. При добавлении матча использовать общую базу `assets/players/players.json`. Не создавать базу для отдельного матча, клуба или турнира; не удалять игроков после смены трансляции.
4. Сохранить работающие плееры, составы, блок «Баланс», поддержку проекта, адаптивность и SEO. Адрес входа в Матч-центр — `/match-center/`.
5. Выполнить `npm test` и `npm run build`, затем проверить опубликованный результат.
