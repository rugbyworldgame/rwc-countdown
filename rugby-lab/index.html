ПОДДЕРЖАТЬ РЕГБИЙНУЮ ЛАБОРАТОРИЮ

Регбийная лаборатория создана по частной инициативе и развивается за счёт личных вложений и поддержки болельщиков.

По мере приближения Кубка мира по регби 2027 года мы будем добавлять новые интерактивные разборы, совершенствовать трёхмерные модели и постепенно переходить к реконструкциям реальных игровых ситуаций.

Если вам нравится проект, поддержите его развитие. Любая сумма помогает создавать новые материалы.

Все материалы бесплатны. Ссылка для добровольной поддержки пока не предоставлена.

Управление камерой: перетаскивание для поворота, колесо мыши или жест двумя пальцами для приближения. Для первой версии используется внешняя загрузка Three.js; перед публикацией библиотеку можно разместить локально.
