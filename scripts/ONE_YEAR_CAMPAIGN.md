# Оформление 1 октября 2026

`menu.js` подключает `assets/js/one-year.js` только до окончания акции. Общий модуль включает `assets/css/one-year.css` и после загрузки CSS проверяет время браузера по абсолютным UTC-границам: `[2026-09-30T21:00:00Z, 2026-10-01T21:00:00Z)`. Это 1 октября по Москве независимо от часового пояса устройства (часы устройства должны быть верными).

Главная: временно скрывает исходные элементы `.hero-copy`, сохраняя их узлы и предыдущее hidden-состояние, оставляет ссылки и весь рабочий таймер. Добавляет праздничный текст и класс оформления. Внутренние страницы: обычная узкая плашка в начале main, без fixed/sticky/перекрытия плеера. При ошибке CSS исходная страница остаётся обычной.

На окончании удаляет временный блок, класс и CSS, восстанавливает исходные hidden-состояния; DOM таймера не меняется. Таймер ставится точно до ближайшей границы (не более 60 секунд), также состояние сверяется при pageshow/focus/visibilitychange для спящих вкладок. Новые открытия после акции ничего не подключают; ручная публикация 2 октября не нужна.

Проверки: `node scripts/check_one_year.mjs`, `npm test`, `npm run build`. Живой проверочный стенд `/checks/one-year.html` (noindex) показывает настоящие страницы при ширине 320/375/1280 px; обхода даты и параметра принудительного показа в production нет. Файлы остаются в истории проекта, после акции не меняют внешний вид.
